# InterviewGPT

AI-powered personalized interview preparation platform.

## Features

- Resume-aware interviews
- Job-description analysis
- Role-specific questioning
- Adaptive follow-up questions
- DSA interview questions
- Voice-to-voice interview
- Speech-to-text
- Text-to-speech
- Answer evaluation
- Final interview feedback
- Interview history
- Dashboard
- JWT authentication
- Secure file uploads
- Rate limiting
- Centralized error handling

## Tech Stack

### Frontend

- React
- Vite
- React Router

### Backend

- Node.js
- Express.js
- MongoDB
- Mongoose

### AI

- GeminiAI API
- GrokAI API
- Ollama Local API

### Authentication

- JWT
- bcrypt
